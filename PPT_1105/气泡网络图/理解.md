# 气泡网络图版制作理解

## 目标

按照 `../PPT_content_气泡网络图.md` 与 `../PPT_skill.md`，生成一页 16:9、可编辑的技术路线 PPT。保留核心和五个能力群组及全部十九个具体节点，不再使用树形图。

## 方案

- 中心为深蓝色“人形应用”圆，左上为暖色大脑端、左下为绿色本体、右上为蓝色场景、右下为紫色小脑、下方为青色数据。
- 圆的直径体现视觉强调，而不是技术成熟度或数据占比；保持指定的模型和本体大小次序。
- 白底、宋体优先、右上角 logo 双向缩小至原图像素尺寸的 50%；主图区域使用 1px 淡蓝边框，标题不加框、不加副标题或页脚。
- 标题按内容文件的完整指定标题显示，不受通用“10字以内”限制；节点短标签保持精简，长技术说明、版本与型号待确认事项放入演讲者备注。
- 配色遵循内容文件，深色圆用白字，浅色圆用深灰蓝字，以可读性优先。
- 原始文件与旧版产物不覆盖；新版的理解、HTML、生成脚本、PPT、PDF及预览均放在本目录。

## 制作流程

1. 以同一套节点坐标和配色生成 HTML 原型。
2. 使用 9010 端口的本地 HTTP 服务与 Playwright 检查 HTML 页面。
3. 将确认的布局导出为原生 PowerPoint 圆形、文字和线条，而不是整页截图。
4. 校验节点覆盖、圆形重叠、线条穿越、文件结构，并渲染 PPT 检查最终画面。

## 字体与内容保留

PPT 指定 SimSun（宋体）；本机没有宋体，HTML 与本机渲染使用 Noto Serif CJK SC 回退，因此预览字体与安装宋体的机器可能略有差异。保留宽松文字区域。

技术名按来源保留，含 Genine SIM、Mojoco、GROOT N1.7；萝博派对型号暂按 RPO，待用户确认，不擅自更正。
